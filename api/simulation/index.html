deistools.simulation¶

Synthetic measurements with known ground truth, for testing and benchmarking estimators. Each model gives a different kind of ground truth — see the concepts pages for what that means in practice.

def simulate(duration_s, sampling_time_s, frequencies, amplitudes, phases,
             impedance_fn, noise_std_V=0.0, noise_std_A=0.0, seed=None):
    """
    Simulate a multisine-excited electrochemical cell.

    impedance_fn(f, t) must return a (n_freq, N) complex array giving the
    frozen-time impedance at each excitation frequency and each sample time.

    Returns a dict with time_s, voltage_V, current_A, Z_true, frequencies_Hz.
    """
    rng = np.random.default_rng(seed)

    N = int(round(duration_s / sampling_time_s))
    t = np.arange(N) * sampling_time_s
    frequencies = np.asarray(frequencies)
    amplitudes = np.asarray(amplitudes)
    phases = np.asarray(phases)

    Z = impedance_fn(frequencies, t)

    current_A = generate_multisine(t, frequencies, amplitudes, phases)
    voltage_V = synthesize_voltage(t, frequencies, amplitudes, phases, Z)

    if noise_std_V > 0:
        voltage_V += rng.normal(0.0, noise_std_V, N)
    if noise_std_A > 0:
        current_A += rng.normal(0.0, noise_std_A, N)

    return {
        'time_s': t,
        'voltage_V': voltage_V,
        'current_A': current_A,
        'Z_true': Z,
        'frequencies_Hz': frequencies,
    }

Stationary R + (R‖C)¶

r_rc ¶

Stationary R + RC circuit (series resistance plus a parallel RC element).

Z(f) = R_s + R_p / (1 + j * 2*pi*f * R_p * C)

All parameters are scalars (time-invariant). Use this as a stationary reference baseline when benchmarking time-varying estimation algorithms.

Transistor-gated R + (R_ct(t)‖C)¶

r_rc_transistor ¶

Non-stationary R + (R_ct(t) || C) circuit, solved as a true time-varying ODE.

A transistor T is placed in series with R_p inside the parallel branch:

R_s ---+--- R_p --- T ---+
       |                 |
       +------- C -------+

The transistor is modelled as a voltage-controlled resistance R_T(V_gate):

V_gate >= V_on        : R_T = 0           (fully conducting, short circuit)
V_off < V_gate < V_on : R_T varies linearly from R_T_max to 0
V_gate <= V_off       : R_T = R_T_max     (fully blocking)

Driving V_gate with a linear ramp makes the effective charge-transfer resistance R_ct(t) = R_p + R_T(V_gate(t)) change continuously, producing a physically motivated non-stationary system. This is the circuit of Breugelmans et al., Electrochim. Acta 76 (2012) 375, Fig. 7 -- the only model in this package that can be built on the bench as well as simulated.

Frozen-time impedance versus true response

The frozen-time (quasi-static) impedance

Z(f, t) = R_s + R_ct(t) / (1 + j*2*pi*f * R_ct(t) * C)

is the ground truth an estimator is supposed to recover, and it is returned as Z_true. It is not, however, the response the circuit actually produces. Because Z depends nonlinearly on R_ct(t), the quasi-static response is only an approximation of the governing equation, valid when R_ct varies slowly compared with the local time constant tau = R_ct*C. At realistic gate-ramp rates the two differ by on the order of 1% rms -- far above the numerical precision of the estimators under test, so the distinction matters.

The voltage returned here is therefore obtained by integrating the circuit equation. Under galvanostatic excitation, with v_C the voltage across the parallel branch:

i(t) = v_C/R_ct(t) + C * dv_C/dt
=>  dv_C/dt = (i(t) - v_C/R_ct(t)) / C
    v(t)    = R_s*i(t) + v_C(t)

a scalar linear ODE with a time-varying coefficient, integrated with fixed-step RK4. voltage_quasistatic_V carries the frozen-time synthesis alongside it so the modelling error is directly observable.

Contrast with legendre.py: there the frozen-time synthesis is algebraically exact, because the basis functions are real and the impedance is linear in them. Here it is not, which is precisely what makes this model useful for testing estimators against a system that does not satisfy their assumptions.

def impedance(f, R_s, R_ct_t, C):
    """Frozen-time impedance, shape (n_freq, N) when R_ct_t is an array."""
    f = np.atleast_1d(f)[:, None]
    Z = R_s + R_ct_t / (1 + 1j * 2 * np.pi * f * R_ct_t * C)
    return Z

def simulate_r_rc_transistor(duration_s, sampling_time_s, frequencies, amplitudes, phases,
                              R_s, R_p, C, V_gate_start, V_gate_rate, R_T_max,
                              V_off=V_OFF_DEFAULT, V_on=V_ON_DEFAULT,
                              noise_std_V=0.0, noise_std_A=0.0, seed=None):
    """Simulate the transistor-gated circuit by integrating its ODE.

    Returns a dict with the usual ``time_s``, ``voltage_V``, ``current_A``,
    ``Z_true`` and ``frequencies_Hz``, plus:

    ``voltage_quasistatic_V``
        The frozen-time synthesis, for comparison. ``voltage_V`` minus this is
        the error incurred by assuming quasi-static behaviour.
    ``R_ct_t``, ``V_gate_t``
        The time-varying charge-transfer resistance and the gate ramp driving it.

    ``Z_true`` is the frozen-time impedance at each excited frequency and each
    sample, which is the quantity an estimator should recover.
    """
    rng = np.random.default_rng(seed)

    N = int(round(duration_s / sampling_time_s))
    dt = sampling_time_s
    t = np.arange(N) * dt
    frequencies = np.asarray(frequencies)
    amplitudes = np.asarray(amplitudes)
    phases = np.asarray(phases)

    def gate(tq):
        return V_gate_start + V_gate_rate * tq

    def r_ct(tq):
        return transistor_r_ct(gate(tq), R_p, R_T_max, V_off, V_on)

    V_gate_t = gate(t)
    R_ct_t = r_ct(t)

    tau_min = float(np.min(R_ct_t) * C)
    if dt > 0.1 * tau_min:
        warnings.warn(
            f"sampling_time_s={dt:.3g} is not small against the fastest circuit "
            f"time constant tau={tau_min:.3g}; the RK4 integration may be "
            "inaccurate. Reduce sampling_time_s.")

    # Noise-free current drives the circuit; measurement noise is added after.
    current_A = generate_multisine(t, frequencies, amplitudes, phases)
    current_half = generate_multisine(t + 0.5 * dt, frequencies, amplitudes, phases)
    R_ct_half = r_ct(t + 0.5 * dt)

    # Start from the quasi-static state, i.e. as if the circuit had already
    # been running. Starting from v_C = 0 would add a ~5*tau startup transient
    # that has nothing to do with the time variation under study.
    Zp0 = _parallel_impedance(frequencies, R_ct_t[0], C)
    v_C0 = float(np.sum(amplitudes * np.real(Zp0 * np.exp(1j * phases))))

    v_C = _integrate_parallel_branch(dt, current_A, R_ct_t,
                                     current_half, R_ct_half, C, v_C0)
    voltage_V = R_s * current_A + v_C

    Z_true = impedance(frequencies, R_s, R_ct_t, C)
    voltage_quasistatic_V = synthesize_voltage(t, frequencies, amplitudes, phases, Z_true)

    if noise_std_V > 0:
        voltage_V = voltage_V + rng.normal(0.0, noise_std_V, N)
    if noise_std_A > 0:
        current_A = current_A + rng.normal(0.0, noise_std_A, N)

    return {
        'time_s': t,
        'voltage_V': voltage_V,
        'current_A': current_A,
        'Z_true': Z_true,
        'frequencies_Hz': frequencies,
        'voltage_quasistatic_V': voltage_quasistatic_V,
        'R_s': R_s,
        'R_p': R_p,
        'C': C,
        'V_gate_t': V_gate_t,
        'R_ct_t': R_ct_t,
    }

Prescribed Legendre expansion¶

legendre ¶

Legendre polynomial oracle model for non-stationary transfer function estimation.

The transfer function at each excited frequency f_k is parameterised as a sum of Legendre polynomials in time up to order P:

H(f_k, t) = sum_{p=0}^{P} a_p(f_k) * L_p(2*t/T - 1)

where T is the total window length and L_p is the p-th Legendre polynomial.

An additive voltage drift is modelled separately as its own Legendre expansion:

v_drift(t) = sum_{q=0}^{Q} b_q * L_q(2*t/T - 1)

This is exactly the signal model that BLTVA assumes, so the algorithm should recover the coefficients a_p and b_q exactly (up to noise). Use this model as an oracle test: if BLTVA fails to recover known coefficients, there is a bug.

The voltage response is:

v(t) = v_drift(t) + sum_k |H(f_k,t)| * A_k * cos(2*pi*f_k*t + phi_k + angle(H(f_k,t)))
Specifying coefficients

impedance_coefficients : array_like, shape (n_freq, P+1), complex a[k, p] is the coefficient of L_p for frequency f_k. a[k, 0] sets the mean impedance at f_k over the window. a[k, 1] sets a linear variation, a[k, 2] a quadratic one.

drift_coefficients : array_like, shape (Q+1,), real, optional b[q] is the coefficient of L_q for the additive drift. Set to None for no drift (default).

Block-oriented nonlinear system¶

block_oriented ¶

Block-oriented nonlinear time-varying systems, Hallemans TIM 2021 Section II.

This is the system class the BLTVA is actually derived for: parallel branches, each a nonlinear time-invariant block followed by a time-varying gain (Fig. 2)::

y(t) = sum_p  NL_p{u(t)} * b_p(t)

with each branch a Wiener-Hammerstein structure (Fig. 7)::

y_p(t) = f2_p( L^-1{ H_p(s) L{ f1_p(u(t)) } } )

a static nonlinearity, an LTI filter, then another static nonlinearity. Choosing which of the two nonlinearities is the identity gives a Hammerstein branch, a Wiener branch, or a purely linear one.

Why this model and not the frozen-time one

legendre.py and r_rc_transistor.py both prescribe an impedance and synthesise a response from it. Neither can produce nonlinear distortion, so neither can exercise Section V, and neither has a ground truth for the best linear approximation beyond "the impedance we prescribed".

Here the ground truth has to be computed, because the BLA of a nonlinear block is not its linear part. The static nonlinearities move it. The paper obtains it by averaging Y(k)/U(k) over many random phase realisations of the input, which is what :func:best_linear_approximation does. That gives a genuine target for H_p and, from the residuals, for the distortion variances.

Filtering without an ODE solver

f1_p(u) is a static function of a periodic multisine, so it is periodic with the same period, and so is the filter's steady-state response. Filtering in the DFT domain is therefore exact for the periodic steady state, needs no integrator, and no scipy::

Y(k) = H(j*2*pi*f_k) * X(k)

The one thing it omits is the startup transient, which the paper models separately with the alpha_r polynomial rather than treating as signal. Use r_rc_transistor when the transient itself is the object of study.

@dataclass
class SecondOrderLowpass:
    """``H(s) = dc_gain * wn**2 / (s**2 + 2*zeta*wn*s + wn**2)``.

    ``wn`` is in **rad/s**. The paper quotes its natural frequencies in Hz
    ("wn,0 = 0.7 Hz") while naming them ``wn``, which is ambiguous; use
    :meth:`from_hz` to be explicit about which you mean.
    """

    wn: float
    zeta: float
    dc_gain: float = 1.0

    @classmethod
    def from_hz(cls, f_n, zeta, dc_gain=1.0):
        return cls(2 * np.pi * f_n, zeta, dc_gain)

    def response(self, f):
        """``H(j*2*pi*f)``, conjugate-symmetric in ``f`` so the filtered
        signal comes back real."""
        s = 2j * np.pi * np.asarray(f, dtype=float)
        return self.dc_gain * self.wn ** 2 / (s ** 2 + 2 * self.zeta * self.wn * s + self.wn ** 2)

@dataclass
class Branch:
    """One parallel branch: ``f2( filter( f1(u) ) )``, scaled by ``b_p(t)``.

    ``f1`` and ``f2`` default to the identity, so a branch is linear unless
    you say otherwise. ``name`` is only for reporting.
    """

    filter: SecondOrderLowpass
    f1: Callable[[np.ndarray], np.ndarray] = field(default=lambda x: x)
    f2: Callable[[np.ndarray], np.ndarray] = field(default=lambda x: x)
    name: str = ""

    @property
    def is_linear(self):
        probe = np.linspace(-2.0, 2.0, 41)
        return (np.allclose(self.f1(probe), probe)
                and np.allclose(self.f2(probe), probe))

    def apply(self, u, fs):
        """Branch output before the time-varying gain."""
        x = np.asarray(self.f1(np.asarray(u, dtype=float)), dtype=float)
        f = np.fft.fftfreq(x.size, 1.0 / fs)
        filtered = np.fft.ifft(np.fft.fft(x) * self.filter.response(f)).real
        return np.asarray(self.f2(filtered), dtype=float)

def hallemans_2021_system():
    """The three branches of the simulation in Section VII, eq. (91d)-(91g).

    ``NL_0`` is Wiener-Hammerstein (nonlinear either side of the filter),
    ``NL_1`` Hammerstein (nonlinear before), ``NL_2`` Wiener (nonlinear
    after). The distortion of each is weak -- the paper reports the variances
    at least 20 dB below the linear part -- which is the regime where a linear
    approximation is worth making at all.

    Natural frequencies are read as Hz, as printed.
    """
    return [
        Branch(SecondOrderLowpass.from_hz(0.7, 0.15, 1.0),
               f1=lambda x: x + 0.02 * np.tanh(x - 2),
               f2=lambda x: x + 0.03 * np.tanh(x - 1),
               name="NL_0 Wiener-Hammerstein"),
        Branch(SecondOrderLowpass.from_hz(1.0, 0.10, 0.2),
               f1=lambda x: x + 0.08 * x ** 2,
               name="NL_1 Hammerstein"),
        Branch(SecondOrderLowpass.from_hz(1.5, 0.15, 0.2),
               f2=lambda x: x + 0.15 * x ** 3,
               name="NL_2 Wiener"),
    ]

    which equals the BLA only for a linear system; use
    :func:`best_linear_approximation` for the true target.
    """
    rng = np.random.default_rng(seed)
    N = int(round(duration_s / sampling_time_s))
    fs = 1.0 / sampling_time_s
    t = np.arange(N) * sampling_time_s
    frequencies = np.asarray(frequencies, dtype=float)

    current_A = generate_multisine(t, frequencies, np.asarray(amplitudes),
                                   np.asarray(phases))

    b = legendre_basis(N, max(len(branches) - 1, 0))
    voltage_V = np.zeros(N)
    for p, branch in enumerate(branches):
        voltage_V += branch.apply(current_A, fs) * b[:, p]

    drift_V = np.zeros(N)
    if trend_coefficients is not None:
        q = np.asarray(trend_coefficients, dtype=float)
        drift_V = legendre_basis(N, q.size - 1) @ q
        voltage_V = voltage_V + drift_V

    if noise_std_V > 0:
        voltage_V = voltage_V + rng.normal(0.0, noise_std_V, N)
    if noise_std_A > 0:
        current_A = current_A + rng.normal(0.0, noise_std_A, N)

    H_linear = np.stack([br.filter.response(frequencies) for br in branches],
                        axis=1)
    return {
        'time_s': t,
        'voltage_V': voltage_V,
        'current_A': current_A,
        'frequencies_Hz': frequencies,
        'H_linear': H_linear,
        'drift_V': drift_V,
        'branches': branches,
    }

def best_linear_approximation(branches, frequencies, amplitudes,
                              sampling_time_s, duration_s,
                              n_realisations=100, seed=None):
    """Monte Carlo BLA of each branch, as the paper computes its ground truth.

    For every random phase realisation of the multisine, each branch is driven
    on its own and ``Y_p(k)/U(k)`` taken at the excited bins; the mean over
    realisations is ``G_p``. Random phases are what make this converge: the
    distortion is uncorrelated with the input and averages away, while the
    linear part does not.

    Returns ``(G, scatter)``, each ``(n_freq, n_branches)`` -- the BLA and the
    standard error of its mean, so a caller can see whether
    ``n_realisations`` was enough.
    """
    rng = np.random.default_rng(seed)
    N = int(round(duration_s / sampling_time_s))
    fs = 1.0 / sampling_time_s
    t = np.arange(N) * sampling_time_s
    frequencies = np.asarray(frequencies, dtype=float)
    amplitudes = np.asarray(amplitudes, dtype=float)
    bins = np.round(frequencies * duration_s).astype(int)

    ratios = np.empty((n_realisations, frequencies.size, len(branches)),
                      dtype=complex)
    for r in range(n_realisations):
        phases = rng.uniform(0, 2 * np.pi, frequencies.size)
        u = generate_multisine(t, frequencies, amplitudes, phases)
        U = np.fft.fft(u)[bins]
        for p, branch in enumerate(branches):
            ratios[r, :, p] = np.fft.fft(branch.apply(u, fs))[bins] / U

    G = ratios.mean(axis=0)
    scatter = ratios.std(axis=0, ddof=1) / np.sqrt(n_realisations)
    return G, scatter

def frozen_impedance(G, N):
    """``Z(f, t) = sum_p G_p(f) b_p(t)``, shape ``(n_freq, N)``.

    The time-varying transfer function a BLTVA of this system should return.
    Identical in form to the Legendre model, which is the point: a *linear*
    block-oriented system is exactly that model with ``a_p(f) = H_p(j2*pi*f)``.
    """
    G = np.atleast_2d(G)
    return G @ legendre_basis(N, G.shape[1] - 1).T
